# Reverse Bin v0.0.7

## Highlights

- The internal ACME authorization endpoint on port 9080 now listens only on IPv4 loopback instead of all network interfaces.
- The local single-app runner also binds its development listener to IPv4 loopback.

## Breaking changes

None. Existing applications and public HTTP/HTTPS routing remain compatible.

## Full list of changes

- Add an explicit `127.0.0.1` bind to the packaged ACME authorization listener on port 9080.
- Add an explicit loopback bind to the Caddyfile generated by `utils/run-reverse-bin-app.sh`.
- Add regression checks against adapted Caddy configuration to ensure packaged internal listeners remain loopback-only.
- Update bundled uv to 0.12.5, landrun to v0.1.17, Deno to v2.9.5, SOPS to v3.13.3, and GoAccess to v1.11.
