# Reverse Bin v0.0.13

## Highlights

- Per-app SSH keys are development credentials: sessions can edit the app's source, and `git push reverse-bin@host:. main` deploys into the app checkout. Watch-mode runtimes such as `deno serve --watch` reload on the change.

## Breaking changes

- `rb-ssh` sessions can now modify app source; before, only `data/` was writable. Review `/var/lib/reverse-bin/home/.ssh/authorized_keys` and keep only keys you would trust to change that app's code.

## Full list of changes

- Bundle reverse-bin-detector v0.1.19, which adds `--as-app-dev` (the `--as-app` sandbox with writable app source) and runs `rb-ssh` sessions with it. Caddy-launched apps keep read-only source, so a running app cannot modify its own code.
- To accept pushes, make the app directory a repository with `git config receive.denyCurrentBranch updateInstead`; see "Per-app SSH keys" in the README.
- README, SECURITY-POSTURE.md, and the bundled reverse-bin-web-apps skill describe `--as-app` (production sandbox) and `--as-app-dev` (writable source).
- Refresh uv to 0.13.3.
