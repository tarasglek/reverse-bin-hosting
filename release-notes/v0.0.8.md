# Reverse Bin v0.0.8

## Highlights

- Per-app SSH keys: `ssh -i todo.pem reverse-bin@host` opens a shell, or runs one command, inside the `todo` app's production sandbox.
- The Caddy admin API is disabled in the packaged configs, so sandboxed apps can no longer reconfigure Caddy over `127.0.0.1:2019`.

## Breaking changes

- The `reverse-bin` login shell changes from `/usr/sbin/nologin` to `/usr/lib/reverse-bin/rb-ssh`, which refuses everything except per-app SSH keys. Shells you set yourself are kept.
- `admin off` means `caddy reload` and other admin API calls no longer work; restart `reverse-bin.service` instead. Locally modified Caddyfiles keep your version and need `admin off` added by hand.
- uv 0.13 defaults to Python 3.15 when no suitable interpreter is installed, and enforces `--require-hashes` in included constraints files.

## Full list of changes

- Bundle reverse-bin-detector v0.1.14 with `rb-ssh` and exec-based `--as-app`.
- Install the `/usr/lib/reverse-bin/rb-ssh` symlink, make it the `reverse-bin` login shell, and revert it on removal.
- Install `/etc/ssh/sshd_config.d/reverse-bin.conf`: public keys only, no forwarding, scoped to `reverse-bin`. Reload sshd after upgrading.
- Create `/var/lib/reverse-bin/home/.ssh` (0700); `authorized_keys` stays operator-owned.
- Set `admin off` in the packaged Caddyfiles and check it in the adapted config.
- Document per-app SSH keys and their security guarantees.
- Update bundled uv to 0.13.1, Deno to v2.9.7, and GoAccess to v1.12.
