# Reverse Bin v0.0.12

## Highlights

- Sandboxed apps can resolve DNS on hosts where `/etc/resolv.conf` is a symlink, such as systemd-resolved's stub resolver. Before, `/etc/resolv.conf` gave "Permission denied" inside the sandbox and lookups failed with "Temporary failure in name resolution".

## Breaking changes

None.

## Full list of changes

- Bundle reverse-bin-detector v0.1.18. When `/etc/resolv.conf` is a symlink, the runtime sandbox grants read-only access to its target's directory (for example `/run/systemd/resolve`), so resolver rewrites stay readable. Static apps are unchanged.
