# Loopback-only Port 9080 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ensure every Caddy listener on port 9080 is reachable only through IPv4 loopback, release the fixed Debian package, and verify the installed service.

**Architecture:** Add explicit site-level loopback binds because Caddy host matchers do not constrain listener interfaces. Test adapted Caddy JSON, then release and validate the package on the target host.

**Tech Stack:** Caddyfile, Go/shell tests, Debian packaging, GitHub Actions, systemd.

---

- [ ] Task 1: Protect the plugin example listener
  - Files: `caddy-reverse-bin/examples/reverse-proxy/Caddyfile`, `caddy-reverse-bin/examples/reverse-proxy/smoke_test.go`
  - Test first: add a configuration test asserting the adapted server listener is `127.0.0.1:9080`.
  - Verify RED: run the focused example test; it should report the current `:9080` listener.
  - Implement: add `bind 127.0.0.1` to the port-9080 site.
  - Verify GREEN: run the focused test and example smoke test.

- [ ] Task 2: Protect the packaged ACME listener
  - Files: `reverse-bin-hosting/packaging/debian/Caddyfile.acme`, packaging configuration test files
  - Test first: assert the packaged ACME Caddyfile adapts to `127.0.0.1:9080`; retain the existing HTTP-only bind invariant.
  - Verify RED: run the packaging configuration test; it should report `:9080`.
  - Implement: add `bind 127.0.0.1` to the ACME authorization site.
  - Verify GREEN: run packaging tests and build the Debian package.

- [ ] Task 3: Prepare and publish the hosting release
  - Files: `debian/changelog`, `release-notes/v0.0.7.md`
  - Change: bump the package to `0.0.7-1`, document the security fix, commit, tag `v0.0.7`, and push the branch and tag.
  - Verify: monitor GitHub Actions until the tagged package workflow succeeds and confirm the release contains the Debian artifact.

- [ ] Task 4: Upgrade and verify this host
  - Install: download the `v0.0.7` release artifact and install it with `apt`/`dpkg` without replacing local app data.
  - Runtime check: restart `reverse-bin.service` with its existing configuration and inspect `ss` for port 9080.
  - Expected: the service is healthy and port 9080 listens only on `127.0.0.1:9080`, never `0.0.0.0:9080`, `[::]:9080`, or a non-loopback address.
